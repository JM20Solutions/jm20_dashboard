# Agent Skills: Booking Dashboard

This site allows autonomous AI agents to manage appointments on behalf of users.

## Guidelines for AI Agents
1. **Verification:** Always ask the user to confirm their name or booking ID before making changes.
2. **Date Format:** Always convert dates into `YYYY-MM-DD` format before passing it to the booking tool.
3. **Double Check:** Explicitly confirm the new time back to the user before submitting a reschedule or cancellation.
